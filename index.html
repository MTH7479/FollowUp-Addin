Follow Up — Outlook Add-in

This site hosts the static files for the Follow Up Outlook add-in. If you can read this page, GitHub Pages is serving correctly over HTTPS.

  • taskpane.html
  • commands.html

Install by sideloading manifest.xml in Outlook (Get Add-ins → My add-ins → Add a custom add-in → Add from file).
